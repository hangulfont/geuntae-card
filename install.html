홈 화면에 근태카드 앱 만들기

한 번만 해두면 앱처럼 아이콘을 눌러 바로 출근·퇴근을 찍을 수 있습니다.

아이폰 · Safari

꼭 Safari로 열어야 합니다. 카카오톡이나 네이버 앱 안에서는 홈 화면 추가가 안 됩니다.

  1. Safari로 근태카드 주소를 엽니다.
  2. 화면 아래(또는 위)의 공유 버튼 을 누릅니다. 주소창 옆 ⋯ 버튼 안에 있을 수도 있습니다.
  3. 메뉴를 위로 올려 홈 화면에 추가 를 누릅니다.
  4. 이름이 근태카드인지 확인하고, 오른쪽 위 추가를 누릅니다.
  5. 홈 화면에 생긴 근태카드 아이콘을 눌러 실행하고, Google 계정으로 한 번 로그인합니다.
로그인은 한 번 더 필요합니다. 아이폰은 홈 화면 앱과 Safari의 로그인 정보를 따로 보관해서, 아이콘으로 처음 열 때 다시 로그인해야 합니다. 그다음부터는 계속 유지됩니다.

갤럭시 · Chrome

Chrome 앱으로 엽니다. 카카오톡에서 받은 링크라면 먼저 Chrome으로 여세요.

  1. Chrome으로 근태카드 주소를 엽니다.
  2. 오른쪽 위 점 세 개 를 누릅니다.
  3. 홈 화면에 추가를 누르고, 이어서 설치를 고릅니다. 메뉴에 앱 설치로 나오면 그것을 누릅니다.
  4. 설치 또는 추가를 눌러 마칩니다.
  5. 홈 화면이나 앱 목록의 근태카드 아이콘을 눌러 실행합니다. Chrome에서 이미 로그인했다면 그대로 이어집니다.

갤럭시 · 삼성 인터넷

  1. 삼성 인터넷으로 근태카드 주소를 엽니다.
  2. 아래쪽 메뉴 를 누릅니다.
  3. 현재 페이지 추가 → 홈 화면을 누릅니다.
  4. 추가를 눌러 마칩니다.

이 아이콘이 홈 화면에 생기면 완료입니다. 이제 아이콘을 눌러 바로 출근·퇴근을 찍으세요.
