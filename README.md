# 근태카드

상주 인원이 휴대폰으로 **출근 / 퇴근**을 누르고 **잔업 시간**을 기록하면, 달력에 바로 표시되고 관리자와 팀원이 실시간으로 함께 보는 근태 앱입니다.
GitHub Pages(무료 호스팅) + Firebase(무료 로그인·DB)로 동작합니다.

## 기능

- **퇴근 버튼**: 출근은 따로 누르지 않습니다. 퇴근을 누르면 그날 정규 출근 시각(08:00, 오전반차는 13:00)으로 출근이 함께 기록되고, 잔업 시간이 자동 계산됩니다(고쳐서 저장 가능). 퇴근 전에는 팀 현황에 "미기록"으로 표시됩니다.
- **퇴근을 못 찍은 날**: 연차·반차·특근이 아닌 지난 평일은 정규 근무(08:00~17:00, 잔업 0)로 근무일에 셉니다. 그 사람의 첫 기록일부터 적용되며, 달력에서 그날을 눌러 실제 시각으로 고칠 수 있습니다.
- **오늘 휴가**: 퇴근 버튼 바로 위의 `오전반차` `오후반차` `연차`. 다시 누르면 취소됩니다.
- **한눈에 보는 달력**: 모든 사람의 "이름 잔업시간 / 특근 / 휴가"가 사람별 고정 색으로 날짜마다 표시됩니다. 휴대폰에서는 성을 뺀 이름으로 짧게 표시합니다.
- **좌우 스와이프**로 달을 넘깁니다.
- **특근**: 주말·공휴일에 퇴근을 찍으면 특근으로 기록되고, 출근~퇴근 시각으로 특근 시간을 계산합니다.
- **월 합계**: 근무, 잔업, 특근, 연차를 한 줄로 보여줍니다.
- **팀 현황**: 오늘 상태, 오늘 잔업, 월 잔업, 월 특근을 표로 봅니다.
- **이름**: 가입할 때 본인 이름을 입력합니다. 상단 이름 옆 ✎로 언제든 바꿀 수 있습니다.
- **로그인 유지**: Google 계정으로 한 번 로그인하면 로그아웃할 때까지 유지됩니다.
- **앱으로 사용법**: 화면 아래 버튼을 누르면 아이폰·갤럭시에서 홈 화면 앱으로 만드는 방법(`install.html`)이 나옵니다.

## 근무 조건과 계산 규칙

| 항목 | 기준 |
|---|---|
| 정규 근무 | 08:00 ~ 17:00 (8시간) |
| 점심 | 12:00 ~ 13:00 |
| 잔업 | **17:30부터** 퇴근 시각까지, **30분 단위 내림** |
| 특근 | 주말·공휴일, 출근~퇴근에서 점심(12~13)과 17:00~17:30을 빼고 30분 단위 내림 |

잔업 예시: 17:50 퇴근 → 0시간 · 18:00 → 0.5시간 · **18:35 → 1시간** · 19:00 → 1.5시간 · 20:45 → 3시간
특근 예시: 08:00~17:00 → 8시간 · 08:00~15:10 → 6시간

정규 시간과 잔업 시작 시각은 사람마다 `내 설정`에서 바꿀 수 있습니다.
공휴일은 `app.js`의 `HOLIDAYS`에 **2026년분**이 들어 있습니다. 2027년 이후는 같은 형식으로 추가하세요.

## 처음 설정 (약 10분)

### 1. Firebase 프로젝트 만들기
1. <https://console.firebase.google.com> 에서 **프로젝트 추가**를 누릅니다(Google 애널리틱스는 꺼도 됩니다).
2. **Authentication** → 시작하기 → 로그인 방법에서 **Google**을 사용 설정합니다.
3. **Firestore Database** → 데이터베이스 만들기 → 위치는 `asia-northeast3 (서울)` → 프로덕션 모드로 만듭니다.
4. Firestore의 **규칙** 탭에 이 저장소의 `firestore.rules` 내용을 붙여넣고 **게시**합니다.

### 2. 웹 앱 설정값 넣기
1. 프로젝트 설정(톱니바퀴) → 내 앱 → **웹 앱 추가(</>)** 를 누릅니다.
2. 표시되는 `firebaseConfig` 값을 `firebase-config.js`에 붙여넣고 커밋·푸시합니다.
   이 값은 공개되어도 되는 식별자입니다. 데이터 보호는 보안 규칙이 담당합니다.

### 3. GitHub Pages 켜기
1. GitHub 저장소 → **Settings** → **Pages**로 갑니다.
2. Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 정하고 저장합니다.
3. 1~2분 뒤 `https://<깃허브아이디>.github.io/<저장소이름>/` 으로 접속할 수 있습니다.

### 4. 로그인 허용 도메인 추가
Firebase → Authentication → **설정** → 승인된 도메인에 `<깃허브아이디>.github.io` 를 추가합니다.

### 5. 관리자 등록과 멤버 승인
1. 배포 직후 **관리자 본인이 먼저** 접속해 로그인한 다음, `내 계정을 관리자로 등록`을 누릅니다.
2. 상주 인원에게 주소를 보내 로그인하게 합니다. 처음에는 "승인 대기"로 표시됩니다.
3. 관리자 화면 **팀 현황 → 멤버 관리**에서 `승인`을 누릅니다. 이메일로 미리 추가해 둘 수도 있습니다.

## 사용 팁

- **홈 화면에 추가**: 휴대폰 브라우저 메뉴에서 "홈 화면에 추가"를 누르면 앱처럼 열립니다.
- **카카오톡으로 링크를 받은 경우**: 카카오톡 안의 브라우저에서는 Google 로그인이 막혀 있습니다. 화면의 `기본 브라우저로 열기`를 누르거나 Chrome/Safari로 여세요.
- **미리보기(데모)**: 주소 뒤에 `?demo`를 붙이면 예시 데이터로 동작을 확인할 수 있습니다. 데모 기록은 그 브라우저에만 저장됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 스타일 |
| `app.js` | 동작(로그인, 기록, 달력, 잔업 계산) |
| `firebase-config.js` | Firebase 웹 앱 설정값 |
| `firestore.rules` | 데이터 접근 규칙(승인된 멤버만 읽기, 본인 기록만 쓰기, 관리자는 전체 수정) |
| `manifest.webmanifest`, `icon.svg` | 홈 화면 앱 아이콘 |
